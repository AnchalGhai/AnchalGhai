### 🌊 KarachiFlow — Real-Time Utility Crisis Tracker
> *ZABEFEST Hackathon 2026 Project*

A crowdsourced platform for Karachi citizens to report and track load shedding, water shortages, and tanker crises in real time. Built for 20 million Karachiites who deal with utility failures daily.

**Key Features:** 20-zone heatmap · Crowdsourced verification · Authority dashboard · Auto-escalation · Offline-first reporting

### 🌐 Multi-Campus Enterprise Network — CNDC Project
> *Computer Networks & Data Communications — SZABIST*

Designed and simulated a full-scale multi-campus enterprise network connecting 6 campuses with 30+ VLANs, hierarchical routing, DHCP, and ISP WAN connectivity using Cisco Packet Tracer.

**Key Features:** 6 campuses · 30+ VLANs · Inter-VLAN routing · DHCP pools · VLSM subnetting · Hub-and-spoke WAN topology
